Changed since the control-plane section

  • Flux in each cell instead of one central Argo CD. Cells pull their config, so dedicated Gov cells never accept inbound connections from the control plane.
  • Envoy Gateway instead of ingress-nginx. The ingress-nginx project was retired in March 2026 and no longer receives security fixes.

Check before committing

  • Service endpoints are confirmed live in Riyadh and Jeddah. Still confirm shape capacity, vault limits, and how OCI bills PostgreSQL memory and HA replicas.
  • Nafath access: the agreement and approval process with the operator, and its lead time.
  • How Lago invoices reach ZATCA Fatoora (Phase 2 integration).
  • Payment gateway onboarding requirements for your commercial registration.
